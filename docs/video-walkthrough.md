# Short demo video outline

Aim for about one minute. Record only the demo site and synthetic sample data.
Do not show a cookie, API key, private offers file, or the contents of .env.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:10 | Open the map with “Demo data” shown. | “This is a sample student offers map. You can try it without signing in or entering an API key.” |
| 0:10–0:25 | Click Online, In person, and All; point out a sample pin. | “The tabs filter the offers. Pins show sample in-person locations.” |
| 0:25–0:40 | Choose Import JSON and select a prepared sample export. | “You can choose an offers JSON file from your computer. The page reads it locally; it is not uploaded.” |
| 0:40–0:50 | Choose Demo data again. | “This switches back to the bundled sample.” |
| 0:50–1:00 | Show the README’s optional setup section. | “Connecting the scraper to real WUSA offers is optional and requires your own authorized access. Keep cookies and API keys private.” |

Before recording, prepare a non-sensitive JSON export or use only the built-in
demo data. The demo can be run locally using the README instructions or hosted
from the docs folder with GitHub Pages.
